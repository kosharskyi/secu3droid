## The Bluetooth picker keeps the same half-window viewport while discovery adds rows

Constrain the sheet's inner content to half of the available height while leaving `ModalBottomSheet` itself at the full window constraints. The expanded anchor is calculated from the full dialog height; constraining the outer modifier before `draggableAnchors` also reduces that anchor's reference height and pins the sheet to the top. The outer modifier's test tag reports pre-offset bounds, so use visible content bounds when asserting the rendered anchor. The weighted lazy list uses the fixed inner panel and scrolls as discovery appends devices. Keep Material3's default safe-drawing insets; extra bottom padding or a spacer creates a second gap. Stable MAC keys preserve row identity, but do not prevent a content-sized sheet from changing its height and moving every row.
