## The displayed column count remains the popup value anchor

The count label is tagged as `sensor-columns-value` and sits in the whole clickable row that opens the 2–8 choice menu. Keep this tag on the number text and keep selection callbacks on menu items so the ViewModel remains the only source of persisted columns.

## Gauge dial style is global and independent of view toggles

The style choice affects modern dial cards across the Sensors screen. The legacy screen switch and each gauge's numeric/dial switch remain separate settings.
