## Functions is the accepted selector reference without changing the dialog contract

The user also approved Functions. Selectors use ordinary proportional text rather than numeric emphasis, and both their label and selection must wrap at narrow widths and enlarged font scales. The whole row opens the existing choice dialog. Preserve each clickable parent tag, its `-value` and `-dropdown-indicator` descendants, and the combined label/selection accessibility description and selection state description. Shared parameter selectors and the remaining 17 parameter tabs now follow this pattern; those tabs have not been individually reviewed by the user.

## Selector display text is not a protocol index

An unknown or missing selection stays empty rather than defaulting to the first option. The displayed `no` option maps to protocol code `15` through `mapselCodes`; layout changes must not infer packet values from displayed text or reorder options.

## Group styling must preserve the interleaved control order

Numeric enum order alone does not define the complete form. The load-grid switch precedes MAP offset, the gasoline/gas table selectors precede TPS offset, and VE2/GAS_V_UNI follow MAP2 gradient. These placements survive section styling; numeric edits continue through the existing dialog callback.

## Load-axis units and editability depend on the selected source and mode

Lower/upper values use pressure units only for MAP and MAP+TPS sources (`loadSrcCfg < 2`); TPS/MAF sources use percent. Load-grid mode disables both bounds, and MAP/barometric source disables upper even outside grid mode. Keep these rules driven by protocol source codes rather than localized choice labels.
